# IT-Projects

A collection of hands-on IT projects, learning roadmaps, and technical notes designed to develop practical skills across four core IT domains:

- **Servers** — Server configuration, administration, and infrastructure.
- **Networking** — Network design, IPv4 addressing, subnetting, and troubleshooting.
- **Identity Management** — User accounts, authentication, permissions, and access control.
- **Remote End Device Support** — Endpoint configuration, remote troubleshooting, and technical support.

## Repository Contents

- **Completed Projects:** Practical labs demonstrating technical skills and configurations.
- **Learning Roadmaps:** Structured guides for progressing from foundational concepts to advanced topics.
- **Technical Notes:** Organized reference materials, procedures, and troubleshooting documentation.

## Objectives

- Develop practical, job-relevant IT skills through hands-on projects.
- Build a structured knowledge base for learning and troubleshooting.
- Document project configurations, testing procedures, and solutions.
- Create a portfolio demonstrating technical competency and continuous learning.

## Tools & Technologies

Tools and technologies vary by project and may include Cisco Packet Tracer, Windows administration utilities, networking tools, and other IT platforms.

## Progress

This repository is continuously updated as new projects are completed, existing documentation is improved, and additional technical skills are developed.
